# BlackArch Linux Installation Guide

BlackArch Linux can be installed in several ways, depending on your needs and preferences. This guide will help you choose the most suitable installation method.

## Available Installation Methods

### 1. Live ISO Installation
The Live ISO is the most straightforward way to get started with BlackArch Linux. It provides:
- Complete BlackArch environment
- Graphical and command-line installers
- Ability to test before installing
- Full set of pre-installed tools

[Learn more about Live ISO Installation →](/installation/live-iso.md)

### 2. Network Installation (netinstall)
The netinstall method is ideal for users who want:
- Minimal initial installation
- Custom tool selection
- Latest package versions
- Smaller download size

[Learn more about Network Installation →](/installation/netinstall.md)

### 3. Docker Container
Docker containers offer:
- Isolated testing environment
- Quick deployment
- Minimal resource usage
- Multiple instances capability

[Learn more about Docker Installation →](/installation/docker.md)

## System Requirements

### Minimum Requirements
- CPU: x86_64 processor (64-bit)
- RAM: 2GB (4GB recommended)
- Storage: 20GB (40GB+ recommended)
- Internet connection for installation

### Recommended Requirements
- CPU: Modern multi-core processor
- RAM: 8GB or more
- Storage: 100GB or more
- Fast internet connection
- UEFI-capable system

## Pre-Installation Checklist

Before proceeding with any installation method, ensure you have:

- [ ] Backed up important data
- [ ] Verified system meets minimum requirements
- [ ] Downloaded installation media from official sources
- [ ] Verified download checksums
- [ ] Prepared installation media (USB drive/VM/etc.)
- [ ] Disabled Secure Boot (if applicable)
